### Decisions made (the ones not in §6.4)

1. **Snapshot strategy (Q2 pre-confirmed):** snapshot `agent.memory.steps` JSON to disk via `Run.snapshot(agent)`. Spike confirmed `AgentMemory` is plain (`system_prompt` + `steps` list of typed dataclasses); each step has `.dict()`; reconstruction via `step_type` discriminator works. Resume calls `agent.run(task, reset=False)` after restoring `agent.memory.steps`. ~5s sandbox re-init documented in PauseButton tooltip.
2. **Auto-queue (Q-P2-D):** when `start_run` is called and a run is already `running`/`awaiting_approval`/`paused`, the new run is auto-queued. No 409 returned to the SPA; the response includes `status="queued"`.
3. **File mention size cap:** 32 KB per file (default); `_MAX_MENTION_BYTES` env override. Larger files appear in the unresolved list (the agent is expected to `read_file` if it actually needs them).
4. **Path traversal defense in depth:** client-side warning chip + server-side `resolve_under_workspace` rejection. Both client AND server validate. `GET /api/files` returns 403 for traversal attempts.
5. **File preview syntax highlighting:** explicitly OMITTED per §6.4 (no Monaco, just `<pre>`). Decision §4 explicitly says smolcode is not an IDE.
6. **`subagent_history` fold-in (Phase 0 §14.8 #3):** the Phase 0 followup was folded into Phase 2. `Run.subagent_*` (single) → `Run.subagent_history: list[SubAgentSummary]`. The legacy `run.subagent` property still returns the latest entry for backward compatibility.
7. **`RunManager.__init` patching:** used a `_orig_runmanager_init = RunManager.__init__` + decorator pattern (instead of touching every existing call site) to add `_queue` + `_queue_lock` to the constructor. Cleanest non-breaking way to extend the dataclass-y class.

**Acceptable drift** because every change is load-bearing for the §6.4 acceptance criteria (live e2e tests in §6.4 cover pause/resume/queue/mentions/preview — all unit-tested here).
