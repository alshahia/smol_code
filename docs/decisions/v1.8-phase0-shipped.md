### Decisions made (the ones not in §14)

1. **Test placement:** added new `TestTokenAggregation` + `TestSubAgentEvents` classes to existing `test_run_manager.py` (rather than creating a new `test_runs.py` as §14.3 suggested). Rationale: those classes test `Run` directly which is what `test_run_manager.py` already does; splitting was unnecessary churn.
2. **`Inspector.tsx` extraction:** pulled the right-pane JSX out of `App.tsx` into a new component. Larger than the §14.2 FE-1 estimate (~216 vs ~120) because I added the countdown `setInterval` ticker + the Show full `<details>` toggle alongside the section markup.
3. **`EventStream.groupRows()`:** did this as a pre-render transformation (memoized on the events array) rather than per-render reconstruction. Cleaner than threading nested state through `setEvents` calls; more code, but each render is O(N) and the array is bounded.
4. **`TierSwitcher` fallback path:** moved the `setWarning` + `onChange` calls into a `queueMicrotask` from render so we don't trip the `set-state-in-effect` lint. LocalStorage dismissal persists across reloads.
5. **`RunHistory` `Date.now()`:** snapshotted once on mount via `useState` initializer (avoids React Compiler `purity` warning for `Date.now()` in render).

## Followups recorded for Phase 1 (per decision 0025 §14.8)

1. **Pre-existing MCP test failures on Windows** - Phase 1 PREWORK; recommend decision 0026.
2. **`Run.summary_dict()` + `_run_summary()` lazy import** - consolidate `_MAX_RUN_WALL_S` into a single settings module so `_run_summary` does not cross-import.
3. **`Run.subagent_*` only tracks ONE invocation** - Phase 1 should add `Run.subagent_history: list[SubAgentSummary]` for nested chains.
4. **No browser-side smoke harness** - Phase 0 deferred gate 5. Phase 1 PREWORK: consider Playwright for an automated browser smoke.
5. **Inspector countdown `setInterval` from `useEffect`** - React 19 StrictMode double-mount leaks the interval in dev (cleanup is wired, so no production impact). Documented for the next person.
