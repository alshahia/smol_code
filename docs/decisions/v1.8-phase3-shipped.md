### Decisions made (the ones not in sec 6.5)

1. **Cost rates default strategy (Q5 confirmed (a)):** DEFAULT_COST_RATES covers openai / anthropic / MiniMax / opencode-go with realistic per-1k USD rates. Override via SMOLCODE_COST_RATES (JSON) is fail-closed on bad shape. Unknown provider/model returns 0 (graceful degradation; Dashboard renders --).
2. **Event log for export (Phase 3 sec 6.5 / B5):** added Run.events_log list that publish() appends to UNDER pending_lock (capped at 5000 events, oldest dropped in chunks of 1000). events_snapshot() decodes SSE frames back into dicts without consuming the live queue.
3. **Subagent_history UI consumption (Phase 0 sec 14.8 #3):** Inspector now renders the FULL list (collapsible rows), not just the latest entry via the legacy `run.subagent` accessor. Backward-compatible for older servers.
4. **Keyboard shortcut router:** Mac uses Cmd; non-Mac uses Ctrl. The router also checks document.activeElement as a fallback. Cmd+Enter from an input STILL fires submit (the only shortcut that bypasses the editable guard).
5. **Vitest + axe-core registration:** vitest-axe ships toHaveNoViolations as a plain function, not a Chai matcher record. We register via `expect.extend(axeMatchers as unknown as ...)` + a TS augmentation in setup.ts. Pattern documented for future contributors.
6. **PW-6 e2e smoke:** smoke spec written but not executed in this session. Playwright infra installed; the next session can run `pnpm test:e2e` once dev is up.
